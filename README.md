# PokerPot

A CLI-only ledger for poker-night money between friends.

PokerPot records one thing: who lost how much and who won the resulting pot.
From that ledger it derives session balances, a simplified settlement, full
history and honest accounting statistics. Everything is stored locally in a
single SQLite file. No accounts, no server, no network.

Designed to run natively in Termux on Android as well as on any normal Linux
system.
